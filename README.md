# 优车汇 UCAR HUB —— 二手车严选交易平台（纯前端 Demo）

一套高度还原商用级二手车交易官网的前端项目。**纯静态、零依赖、无需后端、无需构建**，
双击 HTML 文件即可在浏览器中直接预览全部页面与交互。

---

## 一、运行方式（任选其一）

### 方式 1：直接双击打开（最简单，无需任何环境）
1. 进入项目根目录 `hihi/`；
2. 双击 `index.html`，浏览器会自动打开首页；
3. 通过页面顶部的导航栏即可进入全部 9 个页面。

> 因为站点是纯静态页面，所有样式与脚本都通过相对路径 `css/`、`js/` 引入，
> 所以**直接双击打开、无需部署任何服务**即可正常浏览与交互。

### 方式 2：使用 VS Code 的 Live Server 插件（推荐，体验更佳）
1. 用 VS Code 打开 `hihi/` 文件夹；
2. 安装「Live Server」插件；
3. 右键 `index.html` → `Open with Live Server`；
4. 浏览器会自动打开 `http://127.0.0.1:5500/index.html`。

### 方式 3：使用 Python 自带的本地服务（可选）
在项目根目录执行以下任一命令，然后访问 `http://localhost:8000`：

```bash
# Python 3
python -m http.server 8000

# 或 Node.js（需已安装）
npx serve .
```

> 三种方式效果完全一致。若图片加载较慢，是因为车辆实拍图由在线文生图接口实时生成，
> 首次加载会稍慢，图片加载失败时页面会自动显示占位图，不影响浏览。

## 四、数据说明（增强真实感）

- 车源数据由 `js/data.js` 内置生成，覆盖 **2012 ~ 2026 年**的燃油、油电混动、插电混动、纯电车型；
- 价格区间 **1 万 ~ 80 万**，涵盖万元代步车、家用车与豪华车；
- 里程按车龄合理分布在 **1 万 ~ 15 万公里**，并带真实车况标签（无事故 / 精品一手 / 原厂质保等）；
- 车源分布在北京、上海、广州、深圳、杭州、成都等 10 座城市的模拟门店，含地址与客服电话；
- 数据使用**固定随机种子**生成，因此每次刷新页面数据完全一致，避免价格乱跳；
- 全部数据的图片统一走在线文生图接口，按车型与颜色动态生成，尽量做到「图对得上车」。

## 六、常见问题

1. **页面能直接双击打开吗？**
   可以。本项目为纯静态站点，双击任意 HTML 文件即可预览，无需部署服务。

2. **图片加载慢或显示占位图？**
   车辆图片由在线文生图接口实时生成，首次加载可能稍慢；若接口不可用，页面会自动显示占位图，不影响整体结构与交互。

3. **登录、收藏、预约的数据保存在哪里？**
   全部保存在浏览器 `localStorage`，仅当前浏览器可见；清除浏览器数据后会重置。

4. **如何重置演示数据？**
   打开浏览器开发者工具 → Application/存储 → Local Storage，删除以 `uc_` 开头的键即可。
